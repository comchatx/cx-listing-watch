用你自己的话告诉 cx 怎样检查你的 listing，比如“每天检查一次，需要修改时再告诉我”，cx 会按时照做。

## 工作方式

- 输入 `/listing-watch`，加上 ASIN 和你的要求。cx 只会问你没说清的部分：多久检查一次、什么时候告诉你、在哪里告诉你，以及哪些可以不问你就修改。
- cx 会把你的话写成每条 listing 的指令并照此执行，指令存在你的文件里，你可以查看和修改。
- 每次检查时，cx 会查看这条 listing 和市场情况，只把你要求知道的告诉你。

## 用到的插件

它用 cx-listing-playbook 检查 listing，用 Amazon SP-API 连接你的店铺，已安装 Keepa 时用它查看市场历史，用 cx-schedule 定时；如果你需要，还会用 cx-feishu 在飞书上通知你。「插件」页会一并安装其余几个，cx-feishu 只在你选择时安装。没有 cx-feishu 时，cx 会在对话中告诉你。

## 费用

只有在 cx 的电脑开机时才会检查，你需要为开机时长和每次检查读取的数据付费。
