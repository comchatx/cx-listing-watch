告诉 cx 多久检查一次、什么情况要告诉你、哪些可以直接改，cx 会按时查看 listing 和市场，只说你要知道的事。它需要 cx-listing-playbook、Amazon SP-API 和 cx-schedule，「插件」页会一并安装。

你可以这样问：

- 每周一检查 B0EXAMPLE1，转化率比上周低就告诉我。
- 每天检查我的五个新品，被亚马逊标出问题就告诉我。
- 每两周检查一次 B0EXAMPLE1 的标题和五点描述，有要改的告诉我。

你允许直接改的，cx 会在店铺里改好再告诉你。装了 Keepa 时，cx 还会看市场的历史；装了 cx-feishu 时，cx 在飞书上告诉你，否则在对话里告诉你。你的要求会写成每条 listing 的指令，存在你的文件里，可以随时查看和修改。

## 费用

只有在 cx 的电脑开机时才会检查，你需要为开机时长和每次检查读取的数据付费。
