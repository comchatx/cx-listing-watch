# A listing's standing instruction for its watch

- Where the standing instruction for watching a listing is kept, and what it lists, is in `cx-listing-playbook`'s `listing-review` skill and its `references/watch.md`.
- The file holds the seller's own words for that listing.
- The file is in the seller's files: the seller can read it and change it.
